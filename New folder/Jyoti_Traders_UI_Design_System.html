Principles

Four rules before any pixel

Jyoti Traders is opened on a shop counter, not a couch. Every decision below optimizes for that context first, delight second.

Thumb-first density

48dp minimum tap targets even in dense catalog grids — this is used one-handed while a delivery is being weighed.

Status at a glance

Order and stock states carry color and icon and label — legible under harsh shop tube-lighting, never color alone.

Fast by default

Skeletons over spinners, optimistic cart updates, sub-300ms motion. Perceived speed matters more on a ₹8k Android phone.

Trust, visually

Consistent iconography, transparent pricing, no dark patterns — this app moves real trade credit, not impulse buys.

Motion Language

Patterns worth borrowing — rebuilt for touch

The signature moves from reactbits.dev, motion.dev and the Aceternity/Magic-UI-style kits, reduced to vanilla CSS/JS here, with what each one actually becomes in Flutter.

Hover ≠ touch

Every pattern below is demoed with a cursor because that's what this page runs on. Android has no cursor. Ship the touch-native read: hover → press state + HapticFeedback.lightImpact(), cursor-tracked glow → on-tap ripple, not a silent dead interaction copied 1:1 from a web demo.

Industrial Context

Designed for the shop counter, not the demo stage

This ships to kirana store owners on mid-range Android hardware, often outdoors, often mid-transaction. These aren't nice-to-haves.

48dp minimum tap targets

Every button, chip, and stepper — usable with one hand while the other holds stock.

Color is never the only signal

Status badges always pair color with an icon and a label for direct sunlight and color-blind legibility.

Offline-aware states

Cached catalog with a visible "syncing" indicator instead of a blank screen on patchy warehouse wifi.

Tabular numerals everywhere

Prices, quantities and order totals stay decimal-aligned in every list and receipt.

AA contrast, unconditionally

Violet-on-white and teal-on-dark both hold 4.5:1+ — checked, not assumed.

Reduced-motion respected

Every animation on this page — and in the spec below — degrades to an instant state change.
